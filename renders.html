⌨️ Production CLI & Render Commands

# 1. Full end-to-end draft build & timed render with performance recording:
node scripts/render-draft.mjs --version=1

# 2. Local 1080p render using pinned Hyperframes 0.9.67:
cd video && npx --yes hyperframes@0.9.67 render --quality looks --output renders/draft-v1.mp4

# 3. Comprehensive Hyperframes lint, layout, and WCAG AA contrast check:
cd video && npm run check

# 4. Generate 1280x720 thumbnail designs via headless Chrome & FFmpeg:
scripts/build-thumbnails.sh
Render contract & zero-bloat policy: Video renders are deterministic and timed to milliseconds using GSAP timelines registered on window.__timelines. Heavy MP4 files stay out of git and are served locally by node server.mjs (with HTTP 206 seeking) or published via GitHub Releases.
