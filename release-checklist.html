🚀 3 Publish → Release Checklist

✅ Release Checklist: {{VIDEO_TITLE}}

Pre-production, production, and release verification gates (synced with checklists/*.md).

📋 1. Pre-Production

  • video.yaml filled in and ./new-video.sh {{SLUG}} (or init-panel.mjs) run
  • Brief written in spec/project.json (audience, goal, single CTA, tone)
  • Scenes written in script/scenes.json (VO, overlays, timings)
  • Shot list & realAsset footage checked for privacy

🎬 2. Production & Build

  • Background plates generated (scripts/gen-backgrounds.sh) or added to video/assets/bg/
  • Voiceover generated (scripts/gen-voiceover.sh) or added to video/assets/vo/
  • node scripts/build-video.mjs & cd video && npm run check pass
  • Draft rendered (scripts/render.sh draft) and watched end to end

🚀 3. Final Release

  • Final MP4 rendered with scripts/render.sh final (1920×1080, 30fps)
  • No personal data, logins, or API keys visible in any exported frame
  • Thumbnails built with scripts/build-thumbnails.sh (1280×720, < 2 MB)
  • YouTube title, description, chapters, and tags ready from spec/publish.json
