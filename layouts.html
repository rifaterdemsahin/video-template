🔌 Layout API Endpoints

Start the local API server with node scripts/init-panel.mjs (default port 4173):

GET  /api/layouts                 # List all layouts + enabledIds
GET  /api/layouts?enabled=true    # List only selected/enabled layouts
GET  /api/layouts/:id             # Fetch a single layout definition
POST /api/layouts                 # Update selection: {"enabledIds":["full-bleed-title","split-right-media"]}
